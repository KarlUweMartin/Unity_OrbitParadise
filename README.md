## Unity - Orbit Sandbox

A colorful simulation to explore mass, momentum, and gravity.

[Test it on my website](https://www.karluwemartin.de/orbitSandbox/)

#### Usage

- **Create a body:** Hold the left mouse button or touch the screen to create a body. The longer you hold, the greater its mass.
- **Set the velocity:** Drag with the left mouse button or touch to define the force vector along which the body will be ejected. The longer the vector, the greater the resulting velocity.
- **Toggle the UI:** Click the burger menu in the bottom-right corner to show or hide the UI.
  - **Camera rotation:** Use the virtual joystick to smoothly rotate the camera as it orbits the center star.
  - **Center star mass:** Use the slider to adjust the mass of the center star.

#### Technical Details

``` Unity Version: 6000.3.10f1 ```
Optimized for **WebGL** - but should also work on other platforms.
